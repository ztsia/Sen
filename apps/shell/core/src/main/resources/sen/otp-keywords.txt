# The OTP and TAC filter's keywords (spec §6.2, D86). A notification is dropped in native code, before
# anything is stored, when one of these is joined to a code: the keyword, a few linking words, then the
# code ("Your TAC is 482910"), or the code, then the keyword ("482910 is your OTP"). OtpFilter.kt holds
# the linking words and what a code looks like. A keyword alone, or a keyword and a number that merely
# share a notification, drops nothing: a payment ending "Never share your PIN" is kept.
#
# Keywords match as whole words, in any case. English and Malay. One per line; '#' starts a comment.
# OtpFilterTest checks the list against made-up OTPs and payments, and against every anonymised sample
# in docs/notifications.md, none of which may be dropped. Add a keyword when a new sample shows one,
# with the sample anonymised in docs/notifications.md. Security footers ("do not share", "jangan
# kongsi") are deliberately not keywords: payments carry them too.
