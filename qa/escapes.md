# Escapes

Every bug the owner finds by hand that QA passed (D137). Each entry says why QA missed it, the pin
that now catches it, the question the eyes pass asks on every changed screen, which run could have
caught it, and what changed in the tooling so its *kind* isn't missed again. The main session adds
an entry whenever the owner reports one, before fixing it. **An escape is closed only when a tool,
skill or agent changed** (the last column), not by a pin alone: a pin catches that bug, a tool
catches its kind (D139).

`qa-eyes` reads the **Ask** line of every entry and adds it to its fixed questions.
