Models

Where the owner picks each AI job’s model, from the phone, with no release. A list of every job and what it runs on; a page a job, with what it uses now, a test of something else beside it, and every change; one sheet to change it. Drawn at true size in Minted, with dark and Copper where a second look matters.

What I couldn’t make work as written, and what I drew instead

  1. The brief’s sentence for a provider that went off (This job uses its fallback until it is) is true only for Notification wordings. Five of the six jobs on Anthropic have an Anthropic fallback. I drew it on that job, and added a second sentence for the other five.
  2. The offline words (Changes wait until you’re back) with every action disabled: nothing waits, because nothing can be changed. I used the words as given. You’re offline. Changes are off until you’re back would be true.
  3. An all-changes link never appears with the rows the brief gives: the most they reach is five. I drew All changes on a made-up longer log, once.
  4. A typed model’s effort levels are unknown, so “offering only the levels the model has” can’t apply. I drew all four, with a muted line saying so.
  5. Green for a better score is the money-in colour, which patterns 3 keeps for money. I used the look’s accent, with an arrow and words.
  6. A detail page in patterns 7 is a header card, an action bar and a fact grid. The brief’s order (an intro line, Now, Trying, Changes) is a different shape. I drew the brief’s, with the main session’s change: Trying goes above Now when a candidate exists. The job’s name is the app bar’s title, and the one action sits inside the Now card.
  7. The toast after Use it: patterns 7 says a toast appears only when the change isn’t visible. Here the Now card shows it, but Undo is the point, so I drew it as decided.
  8. Long job names don’t fit beside Use without testing and the ✕ in the sheet’s header (Change the researcher is already two lines). The title wraps and the action stays.
  9. At 1.5× text the Trying card’s two columns don’t fit, so they stack: Now, then the candidate. At 360 px they still fit.
  10. The words less and faster are drawn as well as more and slower, in the same grey, so a column reads the same way whichever way it goes.
  11. Sen’s button is not drawn on any of these: patterns 6 puts it on the five tab screens only.

Decided by the main session, after this page was first drawn: with a candidate, the Trying card goes above Now, so after Test it the owner sees the test without scrolling; with no candidate the order is intro, Now, Changes. Change… is an outlined button, so the page never has more than one filled button.

Every phone is 390 × 844 unless it says otherwise, scaled to fit the page; a screen taller than the phone is drawn whole. A strip is a piece of a screen at its true width. Inside them every colour, radius and font is the look’s token; the scrim, the shadows and the keyboard stand-in are plain black and grey. Source: docs/ui/models/design-src/.
