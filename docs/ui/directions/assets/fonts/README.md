# Fonts

The fonts the six looks use, saved here so the design doesn't depend on Google Fonts. Each family's folder has its files (WOFF2, the Latin and Latin Extended subsets) and its licence, the SIL Open Font License 1.1, which allows bundling them in the app. `fonts.css` loads them from this folder.

Written by `docs/ui/directions/fonts.mjs`; run it again when a look changes its fonts. The app hosts its own fonts (`spec_v2.md` §17), from these files.
